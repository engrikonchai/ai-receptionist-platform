# =================================================================
# Public widget runtime — abuse protection & session security
# =================================================================
# Two independent, server-only HMAC-SHA256 secrets used exclusively by
# the public widget runtime (src/app/api/public-widget/*). Generate
# each with a cryptographically random 32-byte value, e.g.:
#
#   openssl rand -hex 32
#
# Use a DIFFERENT random value for each of the two — never reuse one
# secret for both, and never reuse either across environments
# (development/staging/production should each have their own). Never
# commit real values to this file or anywhere else in version control;
# set them directly in your deployment platform's environment variable
# settings (e.g. Vercel Project Settings → Environment Variables).
# Rotating either one invalidates every rate-limit bucket / widget
# session token signed with the old value — safe to do at any time, it
# just means active chat sessions have to restart.
